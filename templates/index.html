📋 Sample Response Format

Your responses.csv must have these 5 required columns. Optional demographic columns (gender, age_group, region, etc.) automatically become filter variables in the Simulator.

Required Columns

respondent_id · version · task · best_item · worst_item

Example Data

respondent_id version task best_item worst_item gender age_group region
R0011152 Male25-34North
R0011238 Male25-34North
R0011371 Male25-34North
R0021126 Female35-44South
R0021243 Female35-44South
…………… ………

Column Descriptions

  • respondent_id — Unique identifier for each person (e.g., R001, R002)
  • version — Design version assigned to this respondent (1, 2, 3, …)
  • task — Card number answered (1, 2, 3, …)
  • best_item — Item ID or label they chose as BEST on this card
  • worst_item — Item ID or label they chose as WORST on this card
  • Optional: gender, age_group, region, … — Any demographic columns (≤20 unique values) become cut variables in the Simulator

Tips

  • Item IDs vs. Labels: Use either numeric IDs (1, 2, 3) or full item labels. The tool auto-converts.
  • One row per task: Each respondent gets one row for each card they answer.
  • Headers required: First row must be column names (respondent_id, version, task, best_item, worst_item).
  • Demographics: Keep values consistent (e.g., always "Male" or "Female", not mixed case).
  • Download template: Use the button below to get a starter CSV template.
